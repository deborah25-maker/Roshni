# Roshni Birthday Story

## Files
- index.html
- style.css
- script.js

## Add your files
Put your background music here:
assets/music/emotional.mp3

Put your childhood photo here:
assets/photos/childhood.jpg

Put your family photo here:
assets/photos/family.jpg

## Run
Open index.html in your browser, or use VS Code Live Server.

The Start button works even if the music/photo files are not present.
